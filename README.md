# Lab Activity Master

A clean, professional Flutter master compilation app for future laboratory activities.

## Requirements covered
- New Flutter project
- Responsive Home Dashboard as a menu
- Navigation to Activity 1 and Activity 2
- StatelessWidget reusable ActivityCard
- StatefulWidget local interactions
- Responsive Column, Row, Expanded, LayoutBuilder and scrolling
- Provider global state management
- Global Dark/Light Theme setting
- Global user name setting
- Instant Home Dashboard updates
- Clean Architecture: Presentation -> Domain -> Data

## Run
flutter pub get
flutter run
